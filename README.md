# タスク帳（Task Notebook）

React + Vite で作った、シンプルなタスク管理アプリです。
ノート風の見た目で、タスクを完了させると判子（はんこ）が押されます。

このREADMEは「Reactを初めて触る人」でも迷わずローカル環境で動かせるように、
手順をすべて書き出しています。上から順番にやれば動きます。

- 仕様（何ができるアプリか）は [`SPEC.md`](./SPEC.md) にまとめています。
  アプリ内の「仕様書を見る」ボタンからも、同じ内容をその場で確認できます。

---

## 1. 事前に必要なもの：Node.js

このアプリを動かすには **Node.js** というソフトが必要です。
（React/Viteのプログラムを実行するための土台になるソフトです）

### すでに入っているか確認する

ターミナル（Macなら「ターミナル」、Windowsなら「PowerShell」や「コマンドプロンプト」）を開いて、
次のコマンドを打ってください。

```bash
node -v
```

`v18.x.x` や `v20.x.x` のようにバージョン番号が表示されればOKです。
「command not found」のようなエラーが出た場合は、Node.jsが入っていません。次に進んでください。

### 入っていない場合：インストールする

以下の公式サイトから、**LTS**（安定版）と書かれているものをダウンロードしてインストールしてください。

- https://nodejs.org/

インストール後、ターミナルを開き直して、もう一度 `node -v` を実行し、
バージョンが表示されることを確認してください。

---

## 2. プロジェクトのファイルを用意する

このアプリのフォルダ（`task-manager-app`）を、パソコンの好きな場所に置いてください。
（すでにダウンロード済みであれば、この手順は不要です）

---

## 3. ターミナルでフォルダに移動する

ターミナルで、`task-manager-app` フォルダの中に移動します。

```bash
cd task-manager-app
```

うまく移動できたか不安な場合は、次のコマンドでフォルダの中身を確認できます。

```bash
ls
```

`package.json` や `src` というファイル・フォルダが表示されていれば、正しい場所にいます。

---

## 4. 必要なパッケージをインストールする

このアプリが使っている部品（React本体やViteなど）を、まとめてインストールします。

```bash
npm install
```

数十秒ほどで完了します。完了すると、`node_modules` という新しいフォルダが作られます。
（これは大量の部品が入ったフォルダなので、中身を見る必要はありません）

---

## 5. 開発用サーバーを起動する

以下のコマンドで、パソコンの中に「自分専用のミニWebサーバー」を立ち上げます。

```bash
npm run dev
```

成功すると、ターミナルに以下のような表示が出ます（数字は環境によって変わることがあります）。

```
  VITE v5.x.x  ready in 300 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

`http://localhost:5173/` の部分をコピーして、Chromeなどのブラウザのアドレスバーに貼り付けて開いてください。
（もしくは、ターミナルによっては `Local:` の後のURLを **Cmd/Ctrlキーを押しながらクリック**すると開けます）

これで「タスク帳」の画面が表示されれば成功です 🎉

---

## 6. 変更を試してみる

`npm run dev` を実行したまま、たとえば `src/App.jsx` の中の

```jsx
<h1 className="title">タスク帳</h1>
```

の「タスク帳」という文字を書き換えて保存してみてください。
ブラウザを手動でリロードしなくても、画面が自動的に切り替わるはずです。
これはViteの「ホットリロード」という機能で、コードを保存するたびに自動で反映してくれます。

---

## 7. 開発サーバーを止める

ターミナルで `Control + C`（Macも同じく Control + C）を押すと、サーバーが止まります。
また `npm run dev` すれば、いつでも再開できます。

---

## 8. 本番用にビルドする（任意）

アプリを配布・公開できる形（静的なHTML/CSS/JSファイル）にまとめたいときは、次を実行します。

```bash
npm run build
```

`dist` というフォルダが作られ、その中に完成したファイル一式が入ります。
このフォルダの中身を、Webサーバーやホスティングサービス（Vercel, Netlifyなど）にアップロードすれば公開できます。

ビルドしたものをローカルで確認したいときは、以下で確認用サーバーが立ち上がります。

```bash
npm run preview
```

---

## 9. データはどこに保存される？

このアプリはサーバーを使わず、ブラウザの **localStorage**（ブラウザ内の保存領域）にタスクを保存しています。
そのため、以下の点に注意してください。

- 同じブラウザ・同じパソコンで開けば、タスクは消えずに残ります。
- 別のブラウザ（例：ChromeとFirefox）や、別のパソコンで開くと、別々のデータになります（共有されません）。
- ブラウザの「閲覧データを削除」を行うと、タスクも消えます。

---

## 10. うまくいかないときは

| 症状 | 確認すること |
|------|--------------|
| `npm: command not found` | Node.jsが正しくインストールされているか確認してください（手順1） |
| `npm install` でエラーが出る | インターネットに接続されているか確認してください |
| ブラウザで真っ白な画面が出る | ターミナルにエラーが出ていないか確認し、`npm run dev` を再実行してみてください |
| ポート(5173)が使われていると言われる | 他のアプリがそのポートを使っている可能性があります。表示されたURLの番号を確認し、必要なら他のアプリを終了してください |

    └── components/

        ├── TaskList.jsx           … タスク一覧
